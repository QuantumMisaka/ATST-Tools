# Installed ATST real-engine runtime acceptance

This directory is a reusable **external abacuslite only** acceptance entry. It
uses an installed ATST candidate wheel, the released abacuslite wheel, explicit
input assets, a site-compatible Python/MPI stack, and one GPU ABACUS binary.
The retained result is an interface and artifact smoke. One-step optimizers and
the short IRC descent do not establish scientific convergence or a valid
reaction path. Dimer is outside this suite.

The inputs in `--assets` are `h2.stru`, `pt.stru`, `h.upf`, `h.orb`, `pt.upf`,
`pt.orb`, `h2_chain.traj`, and `h2_mode.npy`. The initial seven are generated by
the prior paired harness from ATST example inputs; `h2_mode.npy` is a `(2, 3)`
NumPy array with x components `(-1, +1)` and zeros elsewhere. Pseudopotentials,
orbitals, and binary wheels are supplied by the operator and remain outside
source control. `submit.py` records every input byte hash and refuses a wrong
engine hash.

Run `submit.py --help` for the required exact paths and source SHAs. Without
`--execute`, it writes a payload tar and identity record for local inspection.
With `--execute`, it additionally streams that payload through `ssh SAI` and
`srun` into compute-node `/tmp`, then streams a result tar directly back to the
chosen local output directory. Use a **new** output directory for each run.
The job requests one 4V100 node, two GPUs, `improper-gpu`, and three hours,
using account `pku-jianghong`; it sets no CPU, memory, or Slurm export override.
It does not write a persistent file on SAI's quota-limited Home or organization
storage. The runtime assumes the maintained site Python at
`/home/liuzhaoqing/.conda/envs/atst-dev/bin/python` and the recorded ABACUS
module/MPI environment.

The node script runs each case as a named stage and retains checked raw ABACUS
logs, API documents, evidence JSON, manifests, and trajectories in the archive.
Bulky charge-density restart files and potential cubes are excluded from the
streamed archive. Failures and timeouts are recorded in `stages.tsv` and propagate to
the SSH process exit status. The `exit-code.txt` member records the node exit.
`audit.py OUTPUT_DIR` checks archive integrity, source/wheel identity, every
required stage, and every case's evidence. Inspect `audit.json` together with
the raw archive before making any acceptance claim.

The case set is Relax, ASE MD initial/restart, native MD, serial and parallel
NEB, constant-potential baseline/point, vibration, LTS reader Relax, Sella TS,
CCQN, and descent IRC. The prior independent raw energy/force and trajectory
checks are retained. Sella and CCQN require a candidate trajectory and their
manifest; CCQN also requires the final structure and mode manifest. IRC needs
two distinct endpoint frames and a two-direction manifest. Each records the
optimizer's actual `converged` signal, which may be false at the configured
step limit.
